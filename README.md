# 게이미피케이션 분석: 토스 vs 당근

토스(고양이 키우기)와 당근(게임 탭)의 게임 장치를 분석하고,
`토스 → 당근` 상호 제안(오늘의 동네 미션 + 매너온도 상자)을 직접 플레이할 수 있게 만든 과제 페이지입니다.

- `index.html` : 분석 보고서 + 플레이 가능한 프로토타입 (파일 1개로 동작)
- 외부 라이브러리 없음 (웹폰트 Noto Sans KR만 Google Fonts에서 불러옴)

## 로컬에서 보기
`index.html` 파일을 브라우저로 열면 됩니다.

## GitHub Pages로 배포
1. 저장소 Settings → Pages
2. Source: `Deploy from a branch` / Branch: `main` / Folder: `/ (root)` → Save
3. 1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 에서 확인
